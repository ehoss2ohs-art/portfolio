How to preview:
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Use the EN button to switch between Arabic and English.

Notes:
- The site is static and works without a backend.
- Google Fonts needs an internet connection; fallback fonts are included.
- The contact form opens WhatsApp with a prepared message; it does not store messages.
- Sample project descriptions and any illustrative metrics are clearly presented as concepts, not verified client work or actual results.
- Replace the HA initials badge with a personal photo if desired, and update the CV button when a real CV file is ready.
